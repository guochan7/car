## 下午：OpenHarmony 系统调试实验——GPIO 驱动 SG90 舵机

### 完成内容

- 使用 Hi3861 的 GPIO2 输出控制脉冲，驱动 SG90 舵机。
- 通过高电平脉宽控制舵机角度：

  | 高电平时间 | 对应角度 |
  | ---: | ---: |
  | 500 us | 约 0° |
  | 1000 us | 约 45° |
  | 1500 us | 约 90°（中间位置） |
  | 2000 us | 约 135° |
  | 2500 us | 约 180° |

- 编写并调整任务同步逻辑，实现三个同优先级任务按指定顺序控制舵机：
  1. 任务 1 输出一次运行信息，舵机左转 45°；
  2. 等待约 3 秒后，任务 3 输出两次运行信息，舵机右转 45°；
  3. 任务 2 随后输出三次运行信息，舵机回到中间位置。
- 使用互斥锁保护舵机这一共享硬件资源，并使用信号量保证同优先级任务的固定执行顺序。

### 学习收获

- 理解了 SG90 采用约 20 ms 周期 PWM 信号进行角度控制的原理。
- 掌握了 GPIO 输出高、低电平以及微秒级延时的基本使用方法。
- 明确了互斥锁用于保护共享资源；需要严格控制任务先后顺序时，还应配合信号量等同步机制。

## 下午：STM32 PWM 驱动电机

### 完成内容

- 使用 STM32F103 的 TIM4 生成两路 PWM 信号控制双电机速度。
- 配置 PB6（TIM4_CH1）和 PB7（TIM4_CH2）为 PWM 输出引脚。
- 配置 PB14、PB13 为电机方向控制引脚。
- 编写 `Set_Pwm(motor1, motor2)` 函数，实现两个电机独立的正转、反转与速度控制。
- 使用 `PWM_Init(7199, 9)` 配置约 1 kHz 的 PWM 输出频率。
- 通过 `Set_Pwm(2500, 2500)` 设置左右电机以相同速度运行。

### 学习收获

- 掌握了 STM32 定时器 PWM 的基本配置流程：时钟使能、GPIO 复用输出、定时器时基配置和输出比较配置。
- 理解了 PWM 占空比影响电机平均电压，从而影响电机转速。
- 了解了电机方向控制与 PWM 调速需要配合电机驱动模块完成，且控制板、电机驱动板和电机电源必须共地。

## 问题与解决

| 问题 | 解决方法 |
| --- | --- |
| HiBurn 未显示可用串口或连接超时 | 在设备管理器中确认开发板实际 COM 口；关闭占用串口的软件；连接后按开发板 RESET 键进入烧录模式。 |
| HiBurn 无法选择文件 | 选择编译生成的 `Hi3861_wifiiot_app_allinone.bin`，而不是源代码或构建配置文件。 |
| 同优先级任务执行顺序不确定 | 互斥锁保护舵机资源，同时使用信号量进行任务间的顺序同步。 |
