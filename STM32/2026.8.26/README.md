# STM32F103 双电机 PWM 控制

基于 STM32F103 标准外设库的双直流电机控制示例。程序使用 TIM4 输出两路 PWM，分别控制左右电机的速度，并通过两个 GPIO 引脚控制电机转向。

## 功能

- 使用 TIM4 输出约 1 kHz 的两路 PWM。
- 支持左右电机独立调速与正反转。
- 串口以 `115200` 波特率输出启动信息。
- 主程序默认执行：

  ```c
  Set_Pwm(2500, 2500);
  ```

  即两个电机以相同速度正向运行。

## 文件结构

```text
STM32_Motor/
├── main.c      # 主程序与系统初始化
├── motor.c     # 电机方向、PWM 初始化和速度控制
├── motor.h     # 电机引脚及函数声明

```

## 硬件资源

| 功能 | STM32F103 引脚 / 外设 | 说明 |
| --- | --- | --- |
| 电机 A 方向 | PB14 | 高低电平决定方向 |
| 电机 B 方向 | PB13 | 高低电平决定方向 |
| 电机 A PWM | PB6 / TIM4_CH1 | PWM 占空比控制速度 |
| 电机 B PWM | PB7 / TIM4_CH2 | PWM 占空比控制速度 |
| 调试接口 | SWD | 程序关闭 JTAG、保留 SWD |

> 电机不能直接接到 STM32 引脚，必须通过电机驱动模块（如 TB6612、L298N 等）连接。STM32、驱动模块和电机电源必须共地。

## 使用方法

### 1. 添加文件

将 `main.c`、`motor.c` 和 `motor.h` 添加到 STM32F103 工程中。

项目还需要已有的以下文件或函数：

- `stm32f10x.h`：STM32F1 标准外设库。
- `sys.h`：应提供 `u16`、`u32`、`PBout()`、`delay_ms()`、`uart_init()`、`Stm32_Clock_Init()`、`JTAG_Set()` 等定义。
- `colorful_led_Init()`：炫彩灯初始化函数。如工程未使用炫彩灯，可在 `main.c` 中注释此行。

### 2. 调整速度与方向

调用格式：

```c
Set_Pwm(motor1, motor2);
```

参数范围建议为 `-7199` 到 `7199`：

| 示例 | 效果 |
| --- | --- |
| `Set_Pwm(0, 0)` | 停止 |
| `Set_Pwm(2500, 2500)` | 两侧电机正向运行 |
| `Set_Pwm(-2500, -2500)` | 两侧电机反向运行 |
| `Set_Pwm(2500, -2500)` | 原地转向（方向取决于实际接线） |
| `Set_Pwm(7199, 7199)` | 接近最大占空比 |

### 3. 编译与下载

1. 在 Keil MDK 或其他 STM32F103 开发环境中编译工程。
2. 使用 ST-Link / SWD 将程序下载至开发板。
3. 打开串口工具，设置波特率为 `115200`。
4. 复位开发板，串口应输出：

   ```text
   QST青软
   ```

## PWM 参数

`main.c` 中的初始化语句为：

```c
PWM_Init(7199, 9);
```

当系统时钟为 72 MHz 时，PWM 频率约为：

```text
72 MHz / (9 + 1) / (7199 + 1) = 1 kHz
```

## 常见问题

### 电机方向相反

可交换电机驱动模块的电机输出线，或交换 `Set_Pwm()` 中对应电机的正负参数。

### 电机不转

- 检查电机驱动模块是否独立供电。
- 检查 STM32、驱动模块、电机电源是否共地。
- 检查 PB6、PB7 是否接到驱动模块的 PWM / 使能引脚。
- 检查 PB13、PB14 是否接到驱动模块的方向控制引脚。

### 编译提示 `colorful_led_Init` 未定义

若不需要炫彩灯功能，在 `main.c` 中注释：

```c
// colorful_led_Init();
```
